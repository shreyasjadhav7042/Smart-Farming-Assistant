# Smart Farming Assistant

A machine learning-based web application for **crop recommendation** and **agricultural yield prediction**.

## Features

### 1. Crop Recommendation

Recommends a suitable crop based on:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

**Model:** Random Forest Classifier

### 2. Yield Prediction

Predicts crop yield using:

- Crop
- State
- Season
- Crop Year
- Area
- Annual Rainfall
- Fertilizer
- Pesticide
- Average Temperature
- Maximum Temperature
- Minimum Temperature

**Model:** XGBoost Regressor

## Machine Learning Models

### Crop Recommendation

The following models were tested:

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- Support Vector Machine

Random Forest was selected as the final model after hyperparameter tuning.

**Final Parameters:**

```text
n_estimators = 100
max_depth = 10
min_samples_split = 5
```

**Test Accuracy:** 99.55%

### Yield Prediction

XGBoost was used for regression to estimate agricultural yield.

The dataset was cleaned by removing duplicate records, invalid records, and extreme Coconut yield values above 1000.

## How to Run Locally

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd Smart_Farming
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Flask application

```bash
python app.py
```

### 4. Open in browser

```text
http://127.0.0.1:5000
```

## Deployment

The application can be deployed as a Flask Web Service on Render.

**Build Command:**

```bash
pip install -r requirements.txt
```

**Start Command:**

```bash
gunicorn app:app
```

## Important Note

The predictions generated by the application are **machine learning estimates** based on patterns learned from the training data. Crop recommendation and yield prediction should therefore be treated as decision-support outputs rather than guaranteed agricultural outcomes.

## Project Objective

The objective of this project is to demonstrate how machine learning can be applied to agricultural data for:

1. Crop recommendation based on environmental and soil conditions.
2. Agricultural yield prediction using historical crop, weather, and farming data.
