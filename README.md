🌱 Smart Farming Assistant

A Machine Learning-based Smart Farming Assistant designed to help farmers make better agricultural decisions through Crop Recommendation and Crop Yield Prediction.

📌 Project Overview

The system uses two Machine Learning models to support data-driven agriculture:

Crop Recommendation (Classification): Recommends the most suitable crop based on soil nutrients and environmental conditions, achieving approximately 99% accuracy.

Crop Yield Prediction (Regression): Predicts agricultural crop yield using relevant agricultural and environmental features, achieving approximately 80% model performance.

✨ Features

Crop recommendation based on soil and climate conditions.

Agricultural yield prediction using Machine Learning.

Simple and user-friendly web interface.

Real-time predictions through a Flask application.

Data-driven support for agricultural decision-making.

⚙️ How It Works

User enters soil and environmental information.

The classification model recommends a suitable crop.

The user provides relevant agricultural details for yield prediction.

The regression model predicts the expected crop yield.

Results are displayed through the web application.
